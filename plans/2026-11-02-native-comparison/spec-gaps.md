# Gaps and assumptions

- **G-NC-01 — Native provenance:** Identity, hidden context/reasoning, turns, cache behavior,
  actual tokens/cost/quota are unavailable. Coordinator labels remain unverified and values null.
- **G-NC-02 — Scope:** Presentation-only artifact adaptation with fake hosts is neither a live
  orchestrate treatment nor full fixed60. Independent task wording is frozen, not retuned to
  strengthen observed retrieval; 45/52 fixed cases sample the explicit branches and boundaries, not exhaustive inputs.
- **G-NC-03 — Isolation/trust:** Native prompt-only isolation is procedural. Only the approved
  known sibling module root is executable outside QuickJS; installed local dependencies remain
  trusted. Hashes/consistency checks do not authenticate hostile coherent evidence rewrites.
- **G-NC-04 — Resources:** Runtime events can overshoot a batch before the interrupt; final
  output/state checks occur after execution under memory/time limits. No reentrant disposal. Isolate-generated trace events are not immutable/adversarially authenticated;
  accepted host calls are independently observed and forbidden real host capabilities are absent.
- **G-NC-05 — Availability:** Basic aggregate tests use an explicitly synthetic catalog. The
  separate mandatory real-selection campaign gate needs the clean source-equivalent sibling with the exact reviewed tree in HEAD history and its
  already materialized dependencies/bundle. Local-only commit identity is not an admission anchor. Real campaign admission fails closed, never skips or falls back.
- **G-NC-06 — Approval:** Work uses the isolated experimental exception; plan stays draft,
  no step-done/approve/finish/final merge, and parent controls dispatch/publication/full-suite slot.

- **G-NC-07 — Engine preparation:** A concrete later integration test observed a first-case timeout
  before any tools (1905 ms), and runtime source starts its deadline before first WASM loading.
  Common empty-isolate preparation is now separate bounded infrastructure work, not artifact time.
  This explains the setup mechanism but does not establish the cause of the earlier lost-detail
  failure. Production runtime and 1000 ms artifact budgets are unchanged; all failures are retained.
