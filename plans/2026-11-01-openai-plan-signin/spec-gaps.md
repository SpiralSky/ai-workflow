# Experimental gaps and autonomous decisions

- SG-1: Historical system-overview/CLAUDE DeepSeek-only model rule is superseded **only for the explicitly requested OpenAI sign-in feature** by user: “Add sign in to open ai support for ai-workflow workflow runs.” OpenRouter/default models remain unchanged. This is not a fabricated general model approval or permission for live model use.
- SG-2: Original dollar-only budget cannot represent shared ChatGPT allowance. New explicitly selected subscription mode uses call/token/time admission limits; monetary costs remain unknown, never zero. Token totals are a usage proxy, not a remaining allowance API or dollar estimate. Responses cannot enforce max_output_tokens in this preview; token threshold may be exceeded by one in-flight response, and time cancellation cannot undo consumed allowance.
- SG-3: Secondary model requests use a host-mediated reverse stdio MCP extension rather than sending bearer tokens into the container. No auth store mounts or token process arguments. Both roles use the same selected provider; mixed paid/subscription campaigns are intentionally unsupported.
- SG-4: Live login, account eligibility, provider compatibility and Docker integration remain unverified until separately authorized and executed. Dynamic registration/authentication is never triggered by tests or ordinary evaluation startup.
